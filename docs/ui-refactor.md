# 浅色资料库界面重构

## 视觉方向

采用浅灰背景、白色内容面板、青绿色主色和一致的线形图标。用字号、间距、边框区分信息层级；状态色用于成功、错误和重要操作，减少装饰性彩色按钮与 emoji。

桌面侧栏容纳主要页面与下载设置。平板和手机使用顶部横向导航，主要功能无需展开菜单；下载服务入口保留在顶部。页面内容使用统一的标题、说明、筛选工具栏与分页。

## 共享组件

| 组件 | 职责 |
|---|---|
| `AppIcon` | 统一 SVG 图标，不新增图标库依赖 |
| `MovieCard` | 封面、番号、标题、评分状态、元信息、标签与操作区 |
| `MovieActions` | 磁力、Aria2、115 和评分操作；下载操作与偏好操作分组 |
| `EmptyState` | 可解释的空状态和可选下一步操作 |
| `Pagination` | 上一页、下一页、总数与数字跳转 |
| `ImagePreview` | 原生 dialog 预览，支持 Escape 关闭与焦点恢复 |
| `AppNotifications` | 保留页面内成功和失败提醒 |

推荐、打标、搜索和本地收藏共用影片卡片；页面只负责查询与评分业务。评分的禁用状态由响应式数据驱动，不再直接修改按钮 DOM。

## 样式维护

公共样式位于 `frontend/assets/css/main.css`。颜色、背景和边框优先使用 `--canvas`、`--surface`、`--ink`、`--muted`、`--line`、`--accent` 等变量。

卡片根据自身宽度调整内容布局；窄卡片把操作区移到全宽底部，手机进一步分成下载与评分两行。下载与评分按钮至少 44px 高，标签较多时可展开。设置弹框、登录、模型与导入页使用同一套表单和面板样式。

移除了不再使用的 Bootstrap JS，保留 CSS 基础样式；导航、原生图片预览和说明折叠不依赖额外 JavaScript UI 库。原有图片代理来源、下载接口、后台任务和模型格式不变。

## 验证

运行 `npm run build --prefix frontend` 和 `PLAYWRIGHT_CHANNEL=chrome python scripts/smoke_test.py --browser`。也可以先安装 Playwright Chromium 后不指定 `PLAYWRIGHT_CHANNEL`。

浏览器回归覆盖：

- 7 个主页面在 320、390、768、820、1024、1180、1366、1920px 下的溢出与操作区。
- 登录、SSR 数据复用、缩略图与图片来源、图片预览和 Escape 关闭。
- 打标请求及界面状态持久化、模型后台任务。
- 115/Aria2 成功与失败提醒（模拟接口，无真实下载）。

本地验证使用桌面 Chrome 调整视口，未使用真实 iPad 硬件或 iOS Safari。测试数据和截图使用临时资料库，不读取用户的真实影片与凭证。
